# Blue Throttle (Not a Flight Sim)

**Status:** Archived / Delisted from Google Play

## Project Overview
"Blue Throttle" was a solo-developed multiplayer flight simulation game built over 15 months. The project focused on physics-based flight mechanics, real-time networking, and cooperative gameplay. 

At its peak, the game achieved:
*   **17,000+ Downloads** on Google Play
*   **4.40 Star Rating** (based on 270 reviews)

## Why is this repository an archive?
This repository serves as a portfolio archive of the final published APK. The game was originally published on the Google Play Store but was later delisted in 2023. 

The removal was due to standard **Google Play policy updates** (specifically, changes to the Target API level requirements for Android apps). Because the original Unity project files are no longer with me, I was unable to rebuild and re-submit the game to meet the new API targets. 

## Technical Details
*   **Engine:** Unity
*   **Language:** C#
*   **3D Modeling:** Blender
*   **Networking:** Local Wi-Fi multiplayer (allowing players to connect multiple devices for cooperative missions and competitive dogfights).
*   **Platform:** Android (ARMv7 32-bit architecture)

## How to Play
Since the game is no longer on the Play Store and is a 32-bit build, it may not run on the newest Android devices. To run it:
1. Download the `BlueThrottle.apk` file from this repository.
2. Install it on a 32-bit compatible Android device or an Android Emulator (such as BlueStacks or LDPlayer).
3. Ensure "Install from Unknown Sources" is enabled on your device.

*(Note: Because this is an archived APK, it is provided as-is for portfolio demonstration purposes.)*
